A 材料と加工の技術

設計・製図・加工

🪵 木工設計スタジオ

ブラウザ上で木材を3D配置して作品を設計できるアプリ。三面図・木取り図・くぎ位置を自動生成し、設計から製作準備までを1本で。STL書き出しで3Dプリンタとの連携も可能。

使いどころ: 木材加工の題材における「設計・製図」の時間に。手描き製図の前後で使うと、図法の意味が体感的に分かります。

▶ アプリを開く GitHub

🏭 ものづくり工房

レーザー加工機・3Dプリンタ用のデータを生徒が自分で作れるジェネレーター集(ガジェット工房/レーザー工房/ガジェットCAD/レーザーCAD の4本)。難しいCADソフトなしで加工データが完成します。

使いどころ: デジタル工作機械を導入している学校の加工実習に。選択式なので1時間でも成果物が作れます。

▶ アプリを開く GitHub

✂️ 切り絵スタジオ

写真を白黒二値化し、「離れ小島のない=切っても崩れない」切り絵下絵に自動変換。SVG(切り抜き線)/PNGで書き出せます。

使いどころ: レーザー加工機の切り抜き下絵作りに。紙の切り絵として美術・総合との教科横断にも。

▶ アプリを開く GitHub

🪟 組子パターンメーカー

日本の伝統工芸「組子」の文様を選んで並べ、レーザー加工用の透かしパネルSVGを作れます。

使いどころ: 伝統的な木工技術の紹介と、レーザー加工機での製作題材に。昔と今の加工法を比べる導入にも。

▶ アプリを開く GitHub

🖨️ 3Dプリント STLメーカー集

スライダーや地図の操作だけで、3Dプリンタ用のSTLデータができるアプリ5本。CADを覚える前に「データを作る→出力する」を体験できます。

🗃️ 収納ビン(Gridfinity) 🏺 花瓶 💡 透かし絵(リソフェイン) ⛰️ 地形 🏙️ 街並み

使いどころ: 3Dプリンタの紹介・試し出力に。寸法を数値で決める体験は、設計で「機能と寸法」を考える練習になります。地形・街並みは社会科との教科横断にも。

C エネルギー変換の技術

電気の仕組み

⚡ 電気のきほん — 水と電気の流れ

電気を水の流れにたとえて、電流・電圧・抵抗(オームの法則)を体感的に学べる教材。音声解説(ずんだもん)つきで、個別学習にも対応します。

使いどころ: エネルギー変換の単元の導入・復習に。理科の電気分野の学び直しとしても有効です。

▶ アプリを開く GitHub

🚰 水でわかる MOSFET

水門と水車の模型を動かしながら、「電気で操作するスイッチ」MOSFETの3つの端子とON/OFFのしくみを学べます。水の世界と電気回路を並べて同時に動かす構成。micro:bitでモーターを動かす実物の配線例つき。

使いどころ: スイッチング回路の説明に。計測・制御で、micro:bitから大きな電流を扱うしくみの説明にも。

▶ アプリを開く GitHub

🗼 電気のとどけ方ラボ

直流と交流/電池とACアダプタ/送電・配電/50Hzと60Hz/需要と供給のバランスの5つを、操作して確かめるシミュレーター。

使いどころ: 「電気を供給する仕組み」の授業に。なぜ高い電圧で送るのか、なぜ需要と供給をそろえるのかを、数値を動かしながら説明できます。

▶ アプリを開く GitHub

🔋 エネルギーミックス・スタジオ

発電方法の組み合わせ(電源構成)を自分で決めると、電気代・CO2・国産率・停電リスク・必要な設備の量がその場で計算されます。

使いどころ: 発電の単元のまとめや、エネルギー問題を考える課題に。「どの条件を重視したか」を理由とともに発表させる活動に向きます。

▶ アプリを開く GitHub
D 情報の技術

プログラミング・計測制御

💬 双方向プログラミングスタジオ

「ネットワークを利用した双方向性のあるコンテンツのプログラミング」に対応。日本語ブロックプログラミングでチャット→自動応答ボット→じゃんけん対戦を段階的に自作します。ミッション5段階・見本プログラム・生成JavaScriptの表示/改造モード・先生用モニター付き。

※自校で本格利用する場合は、コピーして自校のFirebase(無料)を設定するのがおすすめです(同時接続数とデータ管理のため)。手順はリポジトリ内の先生用ガイドに。

使いどころ: D(2)双方向性のあるコンテンツの単元まるごと(2〜3時間の展開例をガイドに掲載)。

▶ アプリを開く GitHub

🎛️ micro:bit リアルタイムスタジオ

PCの画面から micro:bitをリアルタイムに操作できるアプリ。スライダーを動かすとその場でサーボが回り、LEDが光り、音程が変わります。センサーの値は1秒に20回グラフになり、CSVでも保存可能。MakeCodeと違って書き込み待ちがゼロなので、試して直してを何十回でも繰り返せます。

※micro:bitに「受信役」を最初の1回だけ書き込む準備が必要です(コピー用コードと手順はアプリ内にあります)。USB接続を使うためChrome / Edge 限定です。

使いどころ: 計測・制御の導入に。「センサ→コンピュータ→アクチュエータ」の流れを、値をいじりながら1時間で体感できます。温度・明るさの記録は理科の計測実験にも。

▶ アプリを開く GitHub

🧩 計測・制御スタジオ

「D(3) 計測・制御のプログラミング」対応。ブロックで組んだ判断プログラムで、USBにつないだ本物のmicro:bitをリアルタイム制御します。書き込み待ちゼロ。実機がなくても仮想micro:bit(センサーはスライダー)で全員がプログラミングでき、機体が人数分ない教室でも大丈夫。

※micro:bitの受信役は「micro:bit リアルタイムスタジオ」と同一。書き込み済みの機体はそのまま使えます。Chrome / Edge 推奨(仮想モードのみなら他ブラウザでも可)。

使いどころ: 計測・制御の単元まるごと。ミッション5段階(自動ライト→温度アラーム→自動ドア→防犯センサー→スマートホーム自由課題)・見本プログラムつきで、「計測→判断→制御」を導入から評価課題まで。

▶ アプリを開く GitHub

🔍 計測・制御 逆引きシステム

「暗くなったら」「土がかわいたら」などやりたいことの言葉から、使えるセンサ・アクション装置を逆引きできる索引。北海道教育大学札幌校 石川研究室の授業資料(51件)へつなぎます。問題が思いつかない生徒向けの「もんだいをみつける」入口つき。

※作成者による非公式の索引です。資料そのものは石川研究室のサイトにあります。「先生に送る」機能は作成者の勤務校用なので、他校では索引として使ってください。

使いどころ: 計測・制御による問題解決で、生徒が装置名を知らずに調べられないときに。AIを使えない環境での課題設定の支えになります。

🔔 早押しクイズスタジオ

micro:bitが早押しボタンになる教室ツール。生徒のmicro:bitは電池だけで動き(ケーブル不要)、無線で先生PCに届きます。早押しの回答順とタイム表示・正解判定・効果音、A/Bボタンでの⭕❌全員参加アンケート(リアルタイム棒グラフ)、点呼つき。

※先生用の中継役1台をUSBでPCにつなぎます(書き込みは最初の1回だけ・全生徒分は同じファイルでOK)。Chrome / Edge 限定。

使いどころ: どの教科の復習クイズにも、学活のレクにも。無線の仕組みの教材化(D領域の導入)としても使えます。

🏫 自校で使うには

1. そのまま使う(いちばん簡単)

各教材の「▶アプリを開く」のURLを、QRコードや学習支援アプリで生徒に配るだけです。 ほとんどの教材はデータを端末内にしか保存しないため、そのままお使いいただけます。

2. コピーして自校版を作る

各教材はGitHubで公開しています。ご自身のGitHubアカウントで Fork(コピー)し、 リポジトリの Settings → Pages で公開すれば、自校版のURLが数分で作れます。改変も自由です。

  • 双方向プログラミングスタジオだけは自校版を推奨: 通信に使うFirebase(無料)の同時接続上限が100台のため、複数校で同じURLを使うと授業が重なった際に接続できないことがあります。 設定手順(約10分)は同リポジトリの docs/teacher-guide.md に画面操作レベルで記載しています。

3. 動作環境

Chrome / Edge などの新しいブラウザが動く端末(GIGA端末含む)。タブレットでも動作します。
